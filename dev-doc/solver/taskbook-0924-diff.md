## 一、新版把两步判定写成了官方标准

新 §3.2 开宗明义：先按 3.2.1 逐元素对比，不过再按 3.2.2 LAPACK 残差判据复核。
这与我们 accept 侧已交付的「直审 → 混合容差 → 残差兜底」三层架构同构——设计被
标准侧采纳为正式口径。批量与 info 两处更是逐字应验我们的暂定方案：

- **批量判定官方定案 = 我们的 T8 暂定方案**：逐矩阵按同式算 ratio 并逐矩阵判定，
  任一矩阵超阈值该用例不通过；批内统计只取本 case 内均值，不跨 case 汇总。
  ADDENDUM_batched 的两问就此有了官方答案，**T8 可解除**，批量精度结论可升正式。
- **info 契约官方定案 = 我们的实现**：potrfBatched 逐矩阵 infoArray、potrsBatched
  标量仅报参数错（cuSOLVER Remark 2 同口径）；新增细则「参数错误写 infoArray[0]=-i」。

## 二、与已交付实现的分歧点（需改造 accept criteria）

| 项 | 我们已交付 | 新版官方 | 影响 |
| --- | --- | --- | --- |
| ε | 2⁻²⁴（spec §0 README 口径） | **2⁻²³** ≈ 1.19e-7 | 改一个常数 |
| potrf/potrs 残差阈值 | 收紧式 min(30,max(10·rc,1)) / 上浮式 max(2·rc,30) | **max(5·ratio_cpu, 3·ratio_cpu_mean)** | 换公式 |
| potri 残差阈值 | 收紧式（DPOT03） | **max(5·ratio_cpu, 0.1)** | 换公式，0.1 地板远严于旧口径 |

| potrf 主判目标 | 还原 recon 取指定三角 vs A64（F vs golden 仅诊断） | 3.2.1 逐元素 **F vs golden**（因子唯一性论证），还原表述从正文删除 | 主判/诊断对调 |
| potri 3.2.1 目标 | 双目标（A⁻¹ 直审 + A·A⁻¹ vs I） | 逐元素 C vs golden；A·A⁻¹ 只出现在 3.2.2 残差 | 双目标降回单目标 |

| 覆盖 | 随机 SPD 类记证据不足 | 随机 SPD 细化「均匀与正态各半」；非正定仅限 potrf/potrfBatched | case-gen 后续补类 |
