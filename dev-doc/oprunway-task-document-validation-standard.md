# OpRunway 任务书输入校验标准

任务书先定义算子的开发与验收要求，开发者据此实现算子并提交 PR；OpRunway workflow 再以任务书为权威，判断 PR 是否符合要求。本表只检查任务书是否足以同时充当开发要求和后续验收依据，不检查 PR，也不评审后续用例设计。

本表已接入验收 workflow 的 **CP-B0 任务书输入校验门**（抽 spec 之前）：受控清单落在
`plugin/acc-common/taskdoc_validation_contract.json`，逐项判法在
`plugin/skills/acc-spec/references/taskdoc-validation.md`，结构复核与阻断清单派生由确定性脚本
`plugin/acc-common/validate_taskdoc_input.py` 做。本表仍是这条门的唯一标准来源——改表即改门。

标为“必须”的项目若缺失或存在歧义，workflow 会停下来交用户决策，但**只有两条出路：补齐事实，
或停止验收去找任务书负责人**。阻断项不接受“豁免并记理由”——豁免掉 Golden 标杆、目标硬件或
验收完成条件不会让这些事实凭空出现，只会让下游缺着必需输入继续跑。豁免只对不阻断的待确认项
（特殊语义）开放。决策绑定当轮 source facts 与该项当轮状态，任务书字节一变即整体失效。
本门只检查任务书输入，**不产验收裁决**，也不改变 spec schema 或既有裁决逻辑——
判定仍唯一归确定性脚本链。

| 校验项 | 任务书应明确的内容 | 要求 | 不满足时的处理 |
|---|---|---|---|
| 算子身份 | 算子名称、所属仓/模块、任务或需求编号 | 必须 | 停止，补齐唯一身份 |
| 交付范围 | 本次新增、优化或修复什么；哪些内容明确不在范围内 | 必须 | 停止，确认范围边界 |
| API 与 overload | 要交付的全部接口、调用形态及 overload，例如有 `dim`/无 `dim` | 必须 | 停止，逐个确认 |
| 输入契约 | 输入数量、含义、dtype、rank/shape 范围、layout/format 约束 | 必须 | 缺项停止；范围描述模糊时请求量化 |
| 属性契约 | 属性类型、合法范围、默认值、nullable/optional 语义及属性组合限制 | 必须 | 停止；不得自行选择默认值 |
| 输出契约 | 输出数量、dtype、shape 规则、多输出含义及 optional output 条件 | 必须 | 停止；不能只依据当前实现猜测 |
| 功能语义 | 与哪个标准接口对齐；边界、异常和特殊值行为 | 必须 | 停止，要求给出明确参考或规则 |
| 特殊语义 | tie/重复值、索引选择、NaN/Inf、正负零、空 tensor、标量、负轴等 | 条件必须 | 相关场景存在但未说明时，列为待确认项 |
| Golden 标杆 | 真值来源、准确 API/overload、运行环境，以及组合实现是否允许 | 必须 | 停止；不得由 agent 自选近似参考 |
| 精度额外要求 | 任务书指定的额外、替代或更严格精度要求，例如特定 dtype/输出的 tolerance、错误率、exact 或其他指标 | 可选 | 未声明时使用 workflow 标准；声明不清时停止确认，不得自行解释或放宽 |
| 性能 baseline | 对照实现及准确 API、是否要求同机同卡，以及语义等价依据 | 有性能要求时必须 | 停止；runner form 不能代替 baseline 定义 |
| 性能口径 | kernel-only 或端到端、统计量、warmup/repeat、达标公式和阈值 | 有性能要求时必须 | 停止，补齐可机械判定的口径 |
| 目标硬件 | SoC/产品型号、数量，以及功能、精度、性能分别在哪些硬件验收 | 必须 | 停止；不得从本机环境反推 |
| 交付物与 DUT | 交付工程形态、实际被测构建物，以及测试桥/框架封装是否属于交付 | 必须 | 停止，避免测错对象或把测试桥当 DUT |
| 接入形态 | kernel 直调、ACLNN、Torch 封装等必须交付的调用层级 | 必须 | 停止；不能仅凭可运行路径代替交付要求 |
| 依赖与前置条件 | 必需 toolkit、外部库、参考数据、额外仓或授权环境 | 条件必须 | 缺少时标记阻塞，不进入跑测 |
| 失败与例外规则 | 不支持项、允许挂起项、baseline limitation、已知限制如何处理 | 条件必须 | 不明确时 fail-closed，提交人工确认 |
| 验收完成条件 | 什么情况下可 PASS；是否允许部分覆盖、风险通过或延期项 | 必须 | 停止，避免把局部跑通当最终通过 |
