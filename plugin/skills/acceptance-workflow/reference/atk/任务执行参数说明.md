# 任务执行参数说明

## 说明

本文优先说明 `atk pytorch` 和 `atk aclnn` 的常用参数。基础任务执行流程见 [任务执行](<../01 基础操作/任务执行.md>)。
本文优先说明 `atk pytorch` 和 `atk aclnn` 的常用参数。基础任务执行流程见 [任务执行](<../01 基础操作/任务执行.md>)。

## 基本格式

```shell
atk pytorch <case_file> [options]
atk aclnn <case_file> [options]
```

说明：

- `<case_file>` 支持 JSON、CSV、XLSX、XLS。
- 未显式指定 `--task` 时，默认执行 `accuracy`。
- `atk pytorch` 默认待测后端是 `npu`；`atk aclnn` 默认待测后端是 `aclnn`。
- 标杆后端默认是 `cpu`。
- 若 `case_file` 所在目录下只有一个 `function_*.py`，会自动作为执行插件加载。

## 常用参数

### 设备参数

| 参数 | 说明 | 示例 |
| --- | --- | --- |
| `--devices` | 待测设备编号，逗号分隔。 | `--devices 0,1` |
| `--compare-backend` | 标杆后端类型，默认 `cpu`。 | `--compare-backend npu` |
| `--compare-devices` | 标杆设备编号，逗号分隔。 | `--compare-devices 0` |
| `--compare-host` | 标杆节点主机地址。 | `--compare-host 192.168.1.10` |
| `--compare-port` | 标杆节点端口。 | `--compare-port 9090` |

### 任务参数

| 参数 | 说明 | 示例 |
| --- | --- | --- |
| `--task` | 任务类型，多个任务用逗号分隔。 | `--task accuracy` |
| `--timeout` | 单个任务超时时间，单位秒。 | `--timeout 650` |
| `--concurrency` | 最大并发任务数。 | `--concurrency 4` |
| `-l, --log` | 日志级别，可选 `debug`、`info`、`warning`、`error`、`fatal`。 | `--log debug` |
| `-p, --plugin` | 自定义执行插件文件或目录。 | `--plugin function_max.py` |

## 任务类型

| 任务类型 | 说明 |
| --- | --- |
| `accuracy` | 精度任务。 |
| `accuracy_load` | 与已有标杆输出进行精度对比。 |
| `performance_e2e` | 端到端性能任务，采集 `__call__` 起止耗时。 |
| `performance_device` | Device 性能任务，通过 profiling 采集 device 耗时等信息。 |
| `performance_device_pta` | 通过 torch_npu/torch memory 包采集内存信息。 |
| `memory_device` | 采集算子运行时内存信息。 |
| `performance_camodel` | 采集 camodel 仿真性能数据。 |
| `accuracy_dc` | 确定性计算任务。 |
| `run` | 仅执行算子调用，不做精度对比。 |


### 用例筛选参数

| 参数 | 说明 | 示例 |
| --- | --- | --- |
| `-s, --start` | 执行起始用例下标。 | `atk pytorch pytorch/all_max.json --start 0` |
| `-e, --end` | 执行结束用例下标。 | `atk pytorch pytorch/all_max.json --end 10` |
| `--white_list` | 用例白名单，支持逗号分隔。 | `atk pytorch pytorch/all_max.json --white_list 1,2,3` |
| `--black_list` | 用例黑名单，支持逗号分隔。 | `atk pytorch pytorch/all_max.json --black_list 4,5,6` |
| `--random` | 随机执行用例数量。 | `atk pytorch pytorch/all_max.json --random 50` |
| `-bf, --boundary_filter` | 边界用例筛选。 | `atk pytorch pytorch/all_max.json -bf boundary` |
| `-kf, --keyword_filter` | 按关键字过滤用例。 | `atk pytorch pytorch/all_max.json -kf "[-inf,inf,nan]"` |
| `--loop_nums` | 用例重复执行次数。 | `atk pytorch pytorch/all_max.json --loop_nums 10` |

### 输出参数

| 参数 | 说明 | 示例 |
| --- | --- | --- |
| `-o, --output` | 输出目录。 | `atk pytorch examples/用例执行/pytorch/all_max.json --output ./atk_output_demo` |
| `--save_data` | 导出数据项，格式为 `<item>[:<format>]`，可多次传入。 | `atk pytorch examples/用例执行/pytorch/all_max.json --save_data input:txt --save_data output:bin` |
| `--input-data` | 使用本地输入数据目录执行测试。 | `atk pytorch examples/用例执行/pytorch/all_max.json --input-data /path/to/dataset` |
| `--print_data` | 打印输入、输出或全部数据。 | `atk pytorch pytorch/all_max.json --print_data input` |

`--save_data` 常用格式如下：

```text
--save_data input
--save_data output:bin
--save_data profile:txt
--save_data input_final
```

### 超时参数

| 参数 | 说明 |
| --- | --- |
| `-to, --timeout` | 单个任务最大超时时间，单位为秒。 |
| `-dt, --db_timeout` | 数据表查询最大超时时间，单位为秒。 |

## 常用命令示例

```shell
atk pytorch examples/用例执行/pytorch/all_max.json --devices 0 --end 1
atk pytorch examples/用例执行/pytorch/all_max.json --task performance_device
atk pytorch examples/用例执行/pytorch/all_max.json --white_list 1,2,3 --save_data input:txt --save_data output:txt
atk aclnn aclnn/aclnnUnique.csv --plugin function_custom.py
```

## 透传到底层 `task` 的高级参数

```shell

atk pytorch examples/用例执行/pytorch/all_max.json --task performance_device --trace
```

## 注意事项

- `--white_list` 和 `--black_list` 可以直接写成逗号分隔形式，如 `1,2,3`；ATK 会自动转换为底层需要的格式。
- 多机执行时，`--compare-host` 和 `--compare-port` 应填写服务端在主节点可访问的地址和端口。
- 自定义执行插件建议命名为 `function_*.py`；若同目录下仅有一个匹配文件，会被自动加载。
