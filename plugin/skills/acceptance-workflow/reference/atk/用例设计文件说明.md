# 用例设计文件说明

## 说明

用例设计文件用于描述算子接口、输入参数、生成规则和验收标准。ATK 根据该文件生成测试用例 JSON。

基础用法见 [用例设计](<../01 基础操作/用例设计.md>)。

## 顶层字段

| 字段 | 类型 | 说明                                            |
| --- | --- |-----------------------------------------------|
| `api` | string | API 类型标识，当前主要用于报表展示和兼容。                       |
| `api_type` | string | 执行方式，如 `function`、`method`、`tensor` 或自定义执行方式。 |
| `version` | string | API 版本号，保留字段。                                 |
| `name` | string | 算子名称，如 `torch.max`。                           |
| `aclnn_name` | string | ACLNN 算子名称，如 `MaxDim`。                        |
| `dtype_numbers` | int | 每个数据类型生成的用例数量。                                |
| `extra_numbers` | int/string | 特殊用例数量，可设置为非负整数或 `all`，缺省该字段时默认值为all。         |
| `compute_times` | int/null | 用例计算次数，可用于按计算量设置阈值的场景。                        |
| `expected_error_msg` | string/null | 预期错误信息，可用于错误信息校验。                             |
| `generate` | string | 数据生成规则名称，默认无依赖时使用 `default`。                  |
| `backward` | bool | 是否执行反向计算流程。                                   |
| `standard` | dict | 精度和性能标准。                                      |
| `size_distributions` | list | 泛化用例输入数据大小分布配置。                               |
| `inputs` | list | 算子输入参数列表。                                     |
| `method_inputs` | list/null | `api_type` 为 `method` 时的构造参数。                 |
| `tensor_input` | dict/null | `api_type` 为 `tensor` 时的调用对象。                 |
| `outputs` | int/string/null | 输出结果所在位置或关键字。                                 |

## 输入参数字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string/null | 参数名称。为 `null` 时作为位置参数传入；非空时作为关键字参数传入。 |
| `type` | string | 参数类型，如 `tensor`、`tensors`、`tensor_tuple`、`scalar`、`attr`、`attrs`。 |
| `required` | bool | 是否必选，当前主要作为预留字段。 |
| `backward` | bool | 当顶层 `backward` 为 `true` 时，控制该输入是否设置 `requires_grad`。 |
| `dtypes` | dict | 数据类型取值范围。 |
| `ranges` | dict | 参数取值范围，通常包含 `valid` 和 `invalid`。 |
| `shapes` | dict | Tensor 形状配置。 |
| `tuple_numbers` | dict | 序列类参数的长度配置。 |
| `boundary` | dict | Tensor 边界用例配置。 |
| `align_32B` | bool | 是否生成 32B 对齐和非对齐用例。 |

## 常用参数类型

| 参数类型 | 说明 |
| --- | --- |
| `tensor` | 单个 Tensor。 |
| `tensors` | Tensor 列表。 |
| `tensor_tuple` | Tensor 元组。 |
| `scalar` | 单个标量。 |
| `scalars` | 标量列表。 |
| `scalar_tuple` | 标量元组。 |
| `attr` | 算子属性参数。 |
| `attrs` | 属性列表。 |
| `attr_tuple` | 属性元组。 |

## 常用数据类型

Tensor 和 scalar 常用数据类型包括：

```text
fp64, fp32, fp16, bf16, int64, int32, int16, int8, uint8, bool
```

Attr 常用数据类型包括：

```text
float, int, string, bool
```

## Shape 配置

常用字段如下：

| 字段 | 说明 |
| --- | --- |
| `dim_numbers` | Tensor 维度数量的可选范围。 |
| `dim_values` | 每一维大小的可选范围。 |
| `max_length` | 当前输入允许的最大元素数量。 |

示例：

```yaml
shapes:
  dim_numbers:
    values: [1, 2, 3, 4]
  max_length: 4294967295
```

## Range 配置

`ranges` 用于配置输入参数取值范围：

```yaml
ranges:
  valid:
    values: [ [-5, 5] ]
  invalid:
    values: [ ["nan"], ["inf"] ]
```

常见特殊值包括：

| 特殊值 | 说明 |
| --- | --- |
| `"-inf"` | 最小值或负无穷语义。 |
| `"inf"` | 最大值或正无穷语义。 |
| `"nan"` | NaN 值。 |
| `"null"` | 空 Tensor。 |
| `"default"` | 默认值，通常表示 `None`。 |

## Boundary 配置

`boundary` 仅对 Tensor 类参数生效，且通常需要 `extra_numbers` 为正整数或 `all`。

| 字段 | 说明 |
| --- | --- |
| `has_empty` | 是否生成空 Tensor。 |
| `has_infnan` | 是否生成 inf、-inf、nan 等特殊 Tensor。 |
| `has_scalar` | 是否生成标量 Tensor。 |
| `has_upper_border` | 是否生成上边界 Tensor。 |
| `has_lower_border` | 是否生成下边界 Tensor。 |

## 输出位置

`outputs` 用于指定输出结果：

| 值 | 说明 |
| --- | --- |
| `null` | 使用算子默认返回值作为输出。 |
| int | 使用指定位置参数作为输出。 |
| string | 使用指定参数名对应的数据作为输出。 |

## 用例 JSON 结构

ATK 生成的 JSON 会包含用例 ID、算子名称、输入参数、执行方式和标准配置。示例结构如下：

```json
{
  "id": 0,
  "name": "torch.max",
  "version": "v2.1",
  "api": "pytorch",
  "api_type": "function",
  "standard": {
    "acc": "single_bm",
    "perf": "not_key"
  },
  "inputs": [
    {
      "name": "input",
      "type": "tensor",
      "dtype": "fp16",
      "shape": [16, 16],
      "range_values": [-5, 5]
    }
  ]
}
```

## 注意事项

- YAML 缩进必须正确。
- `inputs` 顺序应与算子接口顺序一致。
- 参数之间存在依赖时，应使用 [自定义参数约束](<../03 扩展开发/自定义参数约束.md>)。
- `api_type` 使用自定义值时，需要通过 [自定义执行方式](<../03 扩展开发/自定义执行方式.md>) 注册对应执行逻辑。
