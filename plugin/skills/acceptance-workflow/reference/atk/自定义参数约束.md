# 自定义参数约束

## 扩展目标

自定义参数约束用于处理输入参数之间的依赖关系。默认 [用例生成](<../01 基础操作/用例生成.md>) 会根据 YAML 中的参数范围组合生成用例，但某些算子的参数需要满足额外约束，例如 `dim` 必须落在输入 Tensor 的维度范围内。YAML 字段可查看 [用例设计文件说明](<../02 参考资料/用例设计文件说明.md>)。

## 适用场景

以下情况适合使用自定义参数约束：

- 某个参数依赖另一个参数的 shape、dtype 或取值。
- 默认组合可能生成无效用例。
- 需要根据输入动态设置 `expected_error_msg`。
- 需要对生成后的 `CaseConfig` 做统一修正。

## 接口说明

自定义参数约束需要继承 `CaseGenerator`，并通过 `GENERATOR_REGISTRY.register` 注册名称。注册名称需要与用例设计文件中的 `generate` 字段一致。

核心接口：

```python
def after_case_config(self, case_config: CaseConfig) -> CaseConfig:
    return case_config
```

`case_config` 表示已生成的单条用例配置。用户可以在该接口中修改输入参数、输出参数或预期错误信息。

## 实现步骤

以 `torch.max` 为例，`dim` 参数需要根据输入 Tensor 的维度动态设置。新建 `generate_reduce.py`：

```python
import random

from atk.case_generator.generator.base_generator import CaseGenerator
from atk.case_generator.generator.generate_types import GENERATOR_REGISTRY
from atk.configs.case_config import CaseConfig


@GENERATOR_REGISTRY.register("reduce")
class ReduceGenerator(CaseGenerator):
    def after_case_config(self, case_config: CaseConfig) -> CaseConfig:
        dim = len(case_config.inputs[0].shape)
        if case_config.inputs[0].is_range_null():
            case_config.inputs[1].range_values = [0]
        else:
            case_config.inputs[1].range_values = [random.randint(-dim, max(0, dim - 1))]
        return case_config
```

在 `op_max.yaml` 中配置：

```yaml
generate: reduce
```

## 使用方式

生成用例时通过 `-p` 传入插件文件：

```shell
atk case -f op_max.yaml -p generate_reduce.py
```

如果有多个插件文件，也可以传入目录：

```shell
atk case -f op_max.yaml -p ./plugins
```

## 设置预期错误信息

也可以在自定义约束中动态设置预期错误信息：

```python
def after_case_config(self, case_config: CaseConfig) -> CaseConfig:
    if case_config.inputs[0].dtype == "int64":
        case_config.expected_error_msg = "100002"
    return case_config
```

当算子实际报错信息与 `expected_error_msg` 匹配时，该用例可按预期错误处理。

## 调试建议

- 确认 `generate` 字段与注册名称完全一致。
- 确认插件路径通过 `atk case -p` 传入。
- 如果用例生成结果不符合预期，可先减少 `dtype_numbers`，生成少量用例检查 JSON。
- 修改 `case_config.inputs` 时，应确认输入下标与 YAML 中 `inputs` 顺序一致。
