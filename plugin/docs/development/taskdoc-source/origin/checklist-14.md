# 任务书人工 checklist（14 条）

来源：`task-docs/任务书人工checklist.xlsx` Sheet1，拷贝日期 2026-08-18。
Sheet2 与 Sheet3 为空。源不在本仓，不做自动同步。

| 序号 | 检查项 | 检查标准 |
| --- | --- | --- |
| 1 | 检查章节完整性 | 任务书包含标题、任务概述、功能实现要求、算子工程模式、接口定义、参数说明、软硬件环境要求、精度要求、性能要求、内存要求、自验要求、验收交付件、PR合入地址、参考资料 |
| 2 | 任务书标题 | 要和任务发放纪要里面的任务名一致 |
| 3 | 任务概述 | 包含任务背景、开发语言、算子相关代码仓 |
| 4 | 功能要求 | 列出具体要开发的算子名/接口名、算子/接口本身的算法逻辑或计算公式 |
| 5 | 算子工程模式 | 明确算子的开发工程模式 |
| 6 | 接口定义 | 明确算子的接口定义 |
| 7 | 参数说明 | 包含参数名、参数类型（输入、输出、属性）、数据类型、含义描述、shape，要和“接口定义”章节中的参数一致 |
| 8 | 软硬件环境要求 | 说明硬件系列、CANN版本以及其他依赖三方软件版本 |
| 9 | 精度要求 | 列出所有输入场景的精度阈值 |
| 10 | 性能要求 | 列出所有输入场景的性能要求；需要列出具体的case和对应的标杆性能，case和标杆性能也可以放到自测用例目录；服务器型号要具体，比如A2要指明是910B3还是910B4 |
| 11 | 内存要求 | 说明算子执行过程中的内存占用要求 |
| 12 | 自验要求 | 说明开发者的自验策略和测试输入数据生成规则 |
| 13 | 验收交付件 | 包含算子设计文档、自测用例及测试代码、自测方法、自测报告、个人代码仓的说明。测试文档必须要在cann-competitions仓库提交PR。 |
| 14 | PR申请合入 | 具体到算子仓的目录 |
