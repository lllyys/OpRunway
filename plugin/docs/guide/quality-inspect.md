# 开源仓质量巡检

检查文档能否用、社区页面是否失效。三个 skill 均**只观测，不修改**任何代码或文档。

## 概览

| skill | 检查对象 | 前置 |
| --- | --- | --- |
| `cann-doc-quickstart-check` | 快速入门文档：新手照做能否真跑通 | NPU |
| `cann-doc-tutorial-review` | 进阶教程与代码是否对得上 | 无 |
| `cann-page-inspect` | 昇腾社区 CANN 页面的坏链与过期内容 | Chrome |

三者互相独立，无执行顺序要求。

---

## `cann-doc-quickstart-check`

按文档实际编译并运行，暴露开发者会卡在哪一步。

### 前置条件

可跑真机的环境。该 skill 会真实执行文档中的编译与运行步骤。

### 用法

```text
用 cann-doc-quickstart-check 体检 <仓名> 的快速入门文档。
```

### 需人工指定

**评哪一份文档。** 候选仓与候选文档从当前目录检出后交付确认，不自动选定。

### 产物

两份报告，**第一份是主结论**：

| 报告 | 回答什么 |
| --- | --- |
| 忠实趟 | 纯按文档执行，**卡在第几步、卡在什么上** |
| 探索趟 | 补齐这些缺口后能否跑通，以及完整的文档修订清单 |

探索趟仅在忠实趟受阻且经确认后执行，且只允许注入忠实趟已记录的修订建议本身。

### 范围之外

遇到障碍时的常规做法是绕过去，本 skill 相反——**忠实执行是它的核心约束**：

- 文档未要求 source 的环境不 source
- 文档未写明的参数不添加
- 文档中的错误命令照原样执行
- 受阻时不清缓存、不重试
- 明显笔误照笔误执行，记为缺陷，不修正

依据：探索或许能跑通，但那是模型的能力，不是文档的能力。
**开发者照此文档跑不通这一事实，必须先被如实暴露。**

## `cann-doc-tutorial-review`

静态查证：阅读教程，在代码中核对。

### 前置条件

无。本地即可执行，不需要真机，无编译安装副作用。

### 用法

```text
用 cann-doc-tutorial-review 评一下 <仓名> 的进阶教程。
```

### 需人工指定

**评哪几份文档。** 候选交付确认后执行，支持一次评多份。

### 产物

体检报告一份，缺陷按严重程度排序，每条附证据、确定度与改进建议。

**确定度优先阅读**：标注「疑似」「未找到证据」的条目是核实提示，不是定论。

### 范围之外

以下三条约束决定报告的可信度：

| 不做 | 实际做法 |
| --- | --- |
| 不打玄学分 | 判定某段「讲不清」之前先为其辩护到最强，辩不过才计缺陷。每条须附「读者卡在哪 + 原文 + 改进建议」 |
| 不把查不到当过时 | grep 未命中只说明未出现。结论分**确认对不上** / **疑似过时** / **未找到证据**三档，仅强证据写「确认」 |
| 不逐字对照判定 | 按开发者实际影响判定。示意性例子中变量名对不上属正常适配，不计缺陷；仅当文档要求「粘贴替换进某文件」且照做出错时才计严重 |

## `cann-page-inspect`

遍历社区 CANN 顶部导航全部页签，检出坏链与过期内容。

### 前置条件

本机已装 Google Chrome。复用现有安装，不额外下载。

### 用法

```text
帮我看看昇腾社区 CANN 的页面今天有没有坏链。
输出到：<报告放哪>
```

### 需人工指定

**报告落点。** 省略时会主动询问，**不默认写入当前仓库**。

### 产物

单文件 `report.html`，双击打开：

| 区域 | 内容 |
| --- | --- |
| 检查域 | 本轮扫过的页签数、链接数、内容块数 |
| 按页清单 | 逐页列出问题，区分**今日新增**与**已连续 N 天** |

「已连续 N 天」使同一坏链挂了两周这类情况一眼可见。

遍历覆盖那些点击后地址栏不变的子页签——不展开会漏掉这些页面的大部分内容。

### 范围之外

- 网页内容不进入对话，只输出结论
- 全部正常时只回一句话，不罗列检查过程

---

## 常见问题

| 现象 | 原因 |
| --- | --- |
| 页面巡检报「报告不可信」且未生成报告 | 环境问题：缺依赖、Chrome 无法启动，或站点整体不可达。半份报告比没有报告更具误导性，故不出 |
| 快速入门体检报出大量「文档未说明」 | 属预期输出。忠实执行是该 skill 的核心约束，见其「范围之外」 |
