# 术语

reference 和作战卡里反复出现、但不解释就会理解错的词。

先读这页再读其它 reference。

| 术语 | 含义 |
| --- | --- |
| 待验收算子 | 本轮要判定的那个算子。它的实现是待验收对象，接口声明可读，实现不可读 |
| 基线 | 精度对比的标杆，`torch.xxx` 之类。跑在 CPU 节点上算 golden |
| 分面 | 本 skill 的说法，ATK 没有这个概念。一份 YAML 只能写一个接口名和一种精度标准，所以接口名、输出数量或调用签名不同时，不得不分成两份用例集（如 `aclnnMedian` 与 `aclnnMedianDim`）。能不分就不分；dtype 或比较器不同不是分开的理由。分开时用接口名命名。分之前先确认那批用例该不该测，见「验收范围」 |
| 验收范围 | 由任务书的精度与性能目标划定。任务书的功能描述、工程文档里的语义形态（某个出参传空时换一套语义之类）默认不构造数据、不进必测集，用户明确要求了才测，并把这句话记进 `evidence/constraints.md`。默认只按工程声明的那一份接口签名走 |
| 物化 | 把只有语义轴的组合表填成具体 shape、dtype 和参数取值。物化脚本由 agent 写，`make_yaml.py` 必须在物化之后跑 |
| 组合表 | `must_cover.json` 里的必测组合清单。物化前只有语义轴，物化后才有具体取值 |
| 轴的实际取值 | 把组合表（`must_cover.json`，这一轮要测的组合清单）里某根轴的取值全部取出来。可表达性判的就是这些取值 ATK 写不写得出来 |
| 定位字段 | `name`、`aclnn_name`、`kernel_name`。决定**测哪个接口** |
| 接线字段 | `api_type`、`aclnn_api_type`。决定 ATK **取哪个执行器**，也就是适配器怎么挂上去 |
| 适配器 | 一个注册过的执行器类，补基线与待验收算子之间的绑定差量。基线侧是 `function_<op>.py`，待验收算子侧是 aclnn 执行器 |
| 能力域 | `atk-parameter-capabilities.json`。ATK 能表达哪些参数类型、dtype、容器组合，从 ATK 源码固化并锁版本 |
| 冻结 | 把输入数据落盘并记 SHA256，此后所有执行消费同一份。S2 末尾由 `freeze_inputs.py` 做 |
| golden | 基线节点算出来的参考输出。常规精度比对里它在跑测当场产生，不预先冻结 |
| 回归比对 | 拿 CANN 内置实现当真值，只判「输出相对内置有没有变化」。内置本身没被这轮验收检验过，所以结论只能写「与内置逐位一致」，不能写「精度达标」。跑法见 `builtin-baseline.md` |
| 反证实验 | 故意改坏一条真值数据重跑，确认那条用例真的变 Fail。用来证明比对拓扑接对了——没有它，「真的一致」和「其实在跟自己比」在报告上一模一样 |
| aten | PyTorch 底层算子库。`torch.median` 底下对应一组 C++ **重载**，如 `aten::median.dim(Tensor self, int dim, bool keepdim=False)`。这张重载表就是形参契约本身，可信 |
| 替身 | `torch.overrides.get_testing_overrides()` 给出的纯 Python 假函数，PyTorch 为测试 `__torch_function__` 写的桩。**只保证参数位置大致对得上，不保证形参齐全**，不可单独当真值 |
| 兜底 | 前面所有依据都解释不了时才用的最后一手，比如读 ATK 源码。用了要在证据里留痕 |
| 量具 | `scripts/` 下的脚本。验收期不改，发现缺陷按 SKILL.md 的规则处理 |

## 怎么写才算说清了

下面这些词在本仓被禁用（`tests/test_plain_language.py` 会红）。共同毛病是把
一句话压成两个字，压掉的正是「指什么」——读的人得先猜，猜错就照错的做。

| 别写 | 改写成 |
| --- | --- |
| 出处 | 照哪份文件写的 / 依据（谁要求的、写在哪） |
| 来源文件 | 说清是哪份文件、里面的哪张表 |
| 符号 / 候选符号 | 接口名 / 函数名（如 `aclnnMedian`、`torch.median`） |
| 投影 | 取某根轴的实际取值 |
| 薄壳 | 适配器 |

替换方向是**中文说清楚**，不是换成英文——换成 `signature_source` 一样看不懂。

要指一个具体的东西（文件、字段、命令行参数）时，先用中文说它是什么，
再把名字放进括号：

- ✗ 签名只有一个合法出处
- ✓ 签名只能从待验收算子工程目录里的头文件读（`aclnn_<op>.h`，算子对外的接口声明）

新增禁用词时把替换写法一并写进上表：只禁不给替换，下一个人只会换一个同样难懂的词。
